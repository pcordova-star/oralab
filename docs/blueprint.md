# **App Name**: OralabFlow

## Core Features:

- Online Appointment Booking: Patients can securely schedule appointments online, selecting the exam type (SIBO or H. pylori), preferred date, and time slot. They will provide necessary personal details for booking confirmation.
- Receptionist Agenda & Status Manager: A dashboard for receptionists to view daily appointments, filter by status, and update patient statuses in real-time (e.g., 'Agendado', 'En espera', 'En atención', 'Finalizado').
- TEENS Protocol Guided Execution: The TEENS panel provides a step-by-step visual guide for each exam protocol, indicating current stage, required actions, and facilitating progress through the test.
- Automated Exam Timers & Alerts: For ongoing exams, the system displays real-time countdown timers for each protocol step. Visual and auditory alerts notify the TEENS when it's time for the next action.
- Exam Session Tracker: Allows TEENS to initiate new exam sessions for 'En espera' patients, tracking the start time and the current step of the examination process until its completion.
- AI Patient Prep Tool: An AI tool available to receptionists to generate customized, concise pre-appointment instructions and reminders for patients based on their specific exam type and standard protocols.

## Style Guidelines:

- Color Scheme: A light color scheme emphasizes cleanliness and professionalism. Primary actions and important information will use a calm, yet vibrant blue. `#1C68B6`
- Background Color: A subtle, desaturated cool gray with a hint of blue provides a clean canvas. `#E0E9EE`
- Accent Color: A crisp cyan is used for interactive elements, highlights, and critical alerts to draw attention without being overwhelming. `#19CCCC`
- Headline and body font: 'Inter' (sans-serif) for its modern, highly legible, and objective aesthetic, suitable for clear instructions and data display in a clinical setting.
- Use a set of modern, minimalist line icons that clearly communicate functionality within a clinical and administrative context, avoiding unnecessary adornment.
- The layout features a clean dashboard design with well-defined sections for each module (public web, reception, TEENS). Key interactive elements like buttons are generously sized for quick, efficient use in a fast-paced environment.
- Subtle animations and state transitions will be used for interactive elements, appointment status changes, and especially for timer updates and next-step notifications to ensure critical information is immediately noticeable.
