# Oralab - Salud Digestiva Avanzada

Este es el repositorio oficial de **Oralab**, especializado en tests de aire espirado SIBO e Intolerancias.

## Gestión del Repositorio

Para subir cambios de forma segura, asegúrate de haber configurado tu Token de Acceso Personal (PAT) de GitHub.

### Sincronización y Subida
1. **Sincronizar:** `git pull origin main --rebase`
2. **Agregar:** `git add .`
3. **Confirmar:** `git commit -m "Descripción del cambio"`
4. **Subir:** `git push origin main`
